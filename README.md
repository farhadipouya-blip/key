# کلید (KEY) — سامانه جامع و یکپارچه آموزش، آزمون، مشاوره و خدمات آموزشی

پلتفرم تحت وب ساخته‌شده با **PHP 8.2+ / Laravel 12 / MySQL (MariaDB)** با رابط کاربری کاملاً فارسی و RTL.

## معماری و فناوری‌ها

| بخش | فناوری |
|---|---|
| بک‌اند | PHP 8.2+ — Laravel 12 (MVC) |
| پایگاه داده | MySQL / MariaDB 11 — Migrations + Eloquent ORM |
| احراز هویت | سشن‌محور با کنترل دسترسی نقش/مجوز سفارشی (RBAC) |
| صف و زمان‌بند | Laravel Queue (driver: database) + Laravel Scheduler |
| UI | Blade + Bootstrap 5 RTL + Vazirmatn + Chart.js + MathJax (همه استاتیک، بدون CDN) |
| API | RESTful در `routes/api.php` (Sanctum آماده) |
| امنیت | CSRF, XSS-escape, Prepared Statements (Eloquent), Validation سراسری, Audit Log, محدودسازی نرخ درخواست, کنترل دسترسی سمت سرور |

## ماژول‌ها

- **بانک تست و آزمون** — درس/فصل/مبحث، سؤال تستی و تشریحی، آزمون‌ساز، آزمون آنلاین با ذخیره خودکار، شبیه‌ساز، کارنامه، تحلیل گزینه‌ها، تاریخچه
- **ورود گروهی اطلاعات** — ورود سؤال از Excel (xlsx) / CSV / Word (docx) با پیش‌نمایش و اعتبارسنجی قبل از ثبت، خروجی Excel، فایل نمونه، اسکن امنیتی فایل
- **مرور هوشمند** — الگوریتم SM-2 (فاصله‌دار)، صف روزانه، مرور عقب‌افتاده، کیفیت یادآوری (دوباره/سخت/خوب/آسان)، اتصال خودکار به آزمون‌ها، تحلیل ماندگاری
- **بانک خلاصه و نکته** — خلاصه عمومی/شخصی، دسته‌بندی، جست‌وجو، علامت‌گذاری، یادداشت، افزودن به مرور
- **برنامه مطالعاتی** — برنامه روزانه/چندروزه، ثبت جلسه مطالعه، اهداف، مقایسه برنامه با عملکرد واقعی، بازطراحی (Replan)، گزارش استمرار
- **آکادمی** — دوره (رایگان/پولی)، جلسات، پیشرفت دانشجو، ثبت‌نام خودکار پس از خرید
- **مقالات** — CRUD، دسته‌بندی، تصویر شاخص، SEO، دیدگاه با تأیید
- **مطالعه PDF** — کتابخانه، مطالعه آنلاین، کنترل دسترسی، ثبت پیشرفت، هایلایت و یادداشت
- **کلاس آنلاین** — اسکای‌روم/الوکام/سفارشی، ثبت حضور، فعال‌سازی پس از خرید
- **تکلیف و ارزیابی** — تعریف تکلیف، تحویل فایل/متن، تصحیح و بازخورد مدرس، دفتر نمره
- **گواهینامه** — صدور تکی و گروهی، UUID یکتا، QR Code، استعلام عمومی بدون ورود، ابطال
- **تخمین رتبه و انتخاب رشته** — بانک رشته/دانشگاه/حدنصاب، شانس قبولی، تاریخچه تخمین، گزارش نهایی
- **تحلیل عملکرد** — سطح تسلط درس‌محور، نقاط قوت/ضعف، نمودارها، پیشنهاد اقدام اصلاحی
- **پرونده جامع دانشجو (Student 360)** — همه ابعاد دانشجو در یک صفحه
- **پنل مشاور و کارشناس** — تخصیص دانشجو، جلسه مشاوره، پیگیری، تیکت
- **پایش و مدیریت** — آمار کاربران/آنلاین‌ها/فعالیت، لاگ حسابرسی، نقش‌ها و مجوزها، تنظیمات
- **اشتراک و دسترسی** — پلن‌های ماهانه/سه‌ماهه/سالانه/آزمایشی، کنترل مجوز در بک‌اند، تمدید، انقضا با زمان‌بند
- **فروشگاه و پرداخت** — سبد خرید، کوپن، کیف پول، کش‌بک، درگاه آزمایشی واقعی با callback، فعال‌سازی خودکار دسترسی پس از پرداخت، فاکتور چاپی
- **تیکت و پشتیبانی** — دسته‌بندی، اولویت، ارجاع، پیوست، وضعیت پیگیری
- **چت آنلاین** — گفتگوی خصوصی/گروهی/کلاسی، پیام متنی/فایل/تصویر/صوتی، نظرسنجی، وایت‌برد مشترک
- **اعلان و پیامک** — زنگ اعلان‌ها (Database Channel)، پیامک با درایورهای کاوه‌نگار/SMS.ir/ملی‌پیامک/فراز + وضعیت شبیه‌سازی، OTP آماده
- **مدیریت کاربران** — ۷ نقش، مجوزهای ۳۰گانه، فعال/غیرفعال، تخصیص مشاور
- **کتابخانه رسانه** — پوشه‌بندی، آپلود چندفایلی، جست‌وجو، حذف گروهی، اسکن امنیتی (whitelist mime/extension)
- **مدیریت فونت** — آپلود فونت، وزن‌ها، لایسنس، فعال‌سازی فوری در کل سامانه
- **هوش مصنوعی (اختیاری)** — مربی مطالعه، گزارش خودکار، پیشنهاد پاسخ تیکت — سازگار با OpenAI و Gemini؛ گزارش و پیشنهاد تیکت بدون کلید به‌صورت قانون‌محور محلی کار می‌کند (چت مربی نیازمند کلید است) و پیش‌نیاز هیچ بخش دیگری نیست

## راه‌اندازی سریع

```bash
# ۱) نیازمندی‌ها: PHP >= 8.2 (با افزونه‌های mbstring, xml, mysql, zip, gd, curl, bcmath) + Composer + MySQL/MariaDB
# ۲) نصب
composer install
cp .env.example .env          # مقادیر پایگاه داده را تنظیم کنید
php artisan key:generate
# ۳) پایگاه داده
mysql -u root -e "CREATE DATABASE keydb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
php artisan migrate --seed    # جداول + داده نمونه و حساب‌های آزمایشی
# ۴) اجرا
php artisan storage:link
php artisan serve             # http://127.0.0.1:8000
# ۵) صف و زمان‌بند (اختیاری ولی توصیه‌شده)
php artisan queue:work &      # پردازش پس‌زمینه پیامک و ...
# در crontab هاست:  * * * * * php /path/to/artisan schedule:run >> /dev/null 2>&1
```

راهنمای کامل: `docs/INSTALL.md` — راهنمای مدیریت: `docs/ADMIN_GUIDE.md` — حساب‌های آزمایشی: `docs/TEST_ACCOUNTS.md`

## تست‌ها

```bash
php artisan test    # ۴۰ تست (Feature + Unit) روی پایگاه داده keydb_test
```

## ساختار

```
app/
├── Console/Commands/      # زمان‌بند: مرور، انقضای اشتراک، یادآوری برنامه
├── Http/
│   ├── Controllers/       # ~۳۵ کنترلر ماژول‌محور
│   └── Middleware/        # CheckPermission، EnsureActiveUser، UpdateLastSeen
├── Models/                # ۶۵ مدل Eloquent
├── Notifications/         # اعلان‌ها (Database Channel)
├── Services/              # منطق دامنه: Exam، Review(SM-2)، Commerce، Mastery، Rank، AI، SMS، Xlsx، Import، Media
└── Support/               # helpers (fa_num, fa_date, money, route_if)، Jalali، SettingsRepository
database/
├── migrations/            # ۱۷ migration — ۷۸ جدول
└── seeders/               # نقش‌ها/مجوزها، تنظیمات، محتوای نمونه
resources/views/           # Blade فارسی RTL (layouts, components, ماژول‌ها)
routes/
├── web.php                # بارگذاری خودکار ماژول‌ها
├── modules/               # ۱۸ فایل route ماژول‌محور
└── api.php                # RESTful API
```
