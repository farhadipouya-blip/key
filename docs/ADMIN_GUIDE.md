# راهنمای مدیریت سامانه کلید (KEY)

## نقش‌ها و مجوزها

۷ نقش پیش‌فرض: مدیر کل، مدیر، کارشناس، مشاور، مدرس، تولیدکننده محتوا، دانشجو.
۳۰ مجوز ماژول‌محور (مثل `exams.manage`, `shop.buy`, `counselor.panel`) که از **پنل مدیریت ← نقش‌ها و مجوزها** به نقش‌ها تخصیص داده می‌شوند.
مدیر کل به‌صورت پیش‌فرض همه مجوزها را دارد. کنترل دسترسی همیشه **در بک‌اند** (middleware `permission:` + بررسی مالکیت رکورد) انجام می‌شود.

## جریان‌های اصلی

### ۱. ساخت آزمون (مدرس/مدیر)
1. مدیریت ← درس و مبحث: درس → فصل → مبحث را بسازید.
2. بانک سؤال: سؤال تستی/تشریحی با گزینه صحیح و توضیح ثبت کنید (یا با ورود گروهی از Excel).
3. آزمون‌ساز: آزمون بسازید؛ سؤال‌ها را بر اساس درس/مبحث انتخاب کنید؛ مدت، نمره منفی، بلندشدن را تنظیم و «انتشار» بزنید.

### ۲. آزمون دانشجو و اتصال به مرور
- دانشجو از «بانک تست و آزمون» وارد می‌شود؛ پاسخ‌ها به‌صورت خودکار ذخیره می‌شوند.
- پس از پایان، کارنامه با درصد، صحیح/غلط/نزده و تحلیل گزینه‌ها ساخته می‌شود.
- **سؤال‌های غلط به‌صورت خودکار به صف مرور هوشمند (SM-2) اضافه می‌شوند** و سطح تسلط درس‌ها به‌روزرسانی می‌شود.

### ۳. مرور هوشمند
- صف روزانه هر روز موارد سررسید را می‌آورد؛ کیفیت یادآوری (دوباره/سخت/خوب/آسان) فاصله بعدی را طبق SM-2 تعیین می‌کند.
- خلاصه‌ها و نکته‌ها هم می‌توانند به صف مرور اضافه شوند.

### ۴. فروشگاه و فعال‌سازی خودکار
1. مدیریت فروش: پلن اشتراک/محصول بسازید؛ کوپن تعریف کنید.
2. دانشجو: سبد ← کوپن ← پرداخت (درگاه آزمایشی داخلی؛ برای اتصال به درگاه واقعی، در `ShopController::gatewayCallback` درایور خود را جایگزین کنید).
3. پس از پرداخت موفق: سفارش `paid`، تراکنش `success`، دسترسی (اشتراک/دوره) **خودکار فعال**، کش‌بک به کیف پول، اعلان و لاگ ثبت می‌شود.

### ۵. پنل مشاور
- مدیر: دانشجو را به مشاور تخصیص می‌دهد (کاربران ← تخصیص مشاور).
- مشاور: «پرونده ۳۶۰» هر دانشجو را می‌بیند؛ جلسه مشاوره ثبت می‌کند (اعلان به دانشجو می‌رود)؛ پیگیری می‌سازد؛ تحلیل عملکرد دانشجو را می‌بیند.

### ۶. گواهینامه
- صدور تکی یا گروهی (لیست ایمیل)؛ نسخه فارسی/انگلیسی؛ QR + لینک استعلام عمومی: `/public/verify-certificate`؛ ابطال از پنل.

### ۷. ورود گروهی سؤالات
1. دانلود فایل نمونه از صفحه «ورود گروهی اطلاعات».
2. آپلود xlsx/csv/docx ← **پیش‌نمایش اعتبارسنجی** (سطرهای خطا با دلیل) ← تأیید و ثبت.
3. خروجی Excel بانک سؤال از همان صفحه در دسترس است.

## امنیت و پایش

- همه عملیات حساس در **گزارش‌ها و لاگ** (Audit Log) با IP و کاربر ثبت می‌شود.
- پایش سامانه: کاربران آنلاین، ثبت‌نام‌های جدید، فعالیت‌ها.
- فایل‌های رسانه فقط با پسوندهای مجاز (تصویر/pdf/آفیس/صوت/ویدیو) آپلود می‌شوند؛ php/exe/sh/js/html مسدود است.
- کاربر غیرفعال در هر درخواست از سامانه خارج می‌شود؛ تلاش ورود محدودسازی نرخ دارد.

## تنظیمات سامانه

از **پنل مدیریت ← تنظیمات**: درایور و کلیدهای پیامک، درصد کش‌بک، کلید AI (OpenAI/Gemini)، عنوان سامانه و موارد دیگر. تغییرات با کش به‌سرعت اعمال می‌شود.

## پشتیبان‌گیری و بازیابی

```bash
# پشتیبان:
mysqldump -u USER -p keydb > backup-$(date +%F).sql
# بازیابی:
mysql -u USER -p keydb < backup-2026-11-16.sql
```
پوشه `storage/app` (فایل‌های رسانه و آپلودها) را نیز نگه‌داری کنید.
