# حساب‌های آزمایشی سامانه کلید (KEY)

رمز عبور همه حساب‌ها: **Admin@1234**

| ایمیل | نقش | توضیح |
|---|---|---|
| `admin@key.test` | مدیر کل | دسترسی کامل به همه بخش‌ها |
| `expert@key.test` | کارشناس | پایش، لاگ، ورود گروهی، رسانه، تیکت پشتیبانی |
| `counselor@key.test` | مشاور | پنل مشاور، دانشجویان تخصیص‌یافته، جلسات و پیگیری‌ها |
| `teacher@key.test` | مدرس | تدریس، تصحیح تکالیف، دفتر نمره، کلاس‌ها، بانک سؤال |
| `content@key.test` | تولیدکننده محتوا | مدیریت دوره/مقاله/خلاصه عمومی/رسانه/سؤال |
| `student@key.test` | دانشجو | آزمون، مرور، برنامه، فروشگاه، چت، گواهینامه |

## داده‌های نمونه موجود در Seeder

- ۱۱ درس/فصل/مبحث + ۱۳ سؤال تستی (با گزینه و توضیح)
- ۲ آزمون منتشرشده (یکی با نمره منفی، یکی بدون)
- ۲ دوره آموزشی (رایگان/پولی) با جلسات، ۳ مقاله منتشرشده
- ۵ پلن اشتراک، ۲ محصول، کوپن نمونه
- بانک رشته‌ها و دانشگاه‌ها با حدنصاب برای تخمین رتبه
- تخصیص دانشجو نمونه به مشاور نمونه

> **مهم:** این حساب‌ها فقط برای محیط آزمایش/توسعه هستند. قبل از استقرار واقعی، رمز admin را تغییر دهید و حساب‌های نمونه را حذف یا غیرفعال کنید (`پنل مدیریت ← کاربران`).
